# 侧栏重设计产品规格

日期：2026-10-19 · 版本：v3 · 负责人：产品设计提案 · 状态：方向已确认，第二阶段已落地，真实账号与人工设计验收待完成

## 1. 目标与范围

让侧栏成为稳定的工作入口：快速切换全局模块、返回项目上下文、进入身份授权的业务插件。视觉参考 Codex 的低饱和深色侧栏、轻量行选中、紧凑项目树，保留 Sensteed 品牌。

设计阶段交付独立 HTML 高保真原型和实现规格。实际客户端实施进度与差异见 [实施记录](sidebar-implementation.md)。原型没有连接账户、工作区、插件服务或对话服务；产品中的所有真实操作仍需后续实现。本轮不启动桌面应用、不触发打包。

## 3. 设计决策（v2，依据用户确认更新）

采用“固定模块窄栏 + 可独立收起的上下文侧栏 + 主工作区”。用户已明确认可双层结构，以及按身份展示供应链管理、财务管理等业务插件的方向。本版取代 v1 单侧栏提案。

第一层回答“我在哪个工作模块”，第二层回答“当前模块中正在处理什么”。主页的项目和会话区域不再混排插件、技能、设置等全局入口。第二层收起后，第一层仍完整保留；主区顶栏提供重新展开按钮。

固定窄栏上部是主页、知识与记忆、定时任务、插件、技能；下部为已安装且当前身份可访问的业务插件；最底部仅保留账户头像，点击打开设置弹框。模块多时模块区单独滚动，账户头像不滚走。品牌图标保持独立，无额外不明确的跳转。

仅具有独立导航页的业务插件进入窄栏；仅提供工具调用或后台服务的插件仍由对话调用。技能始终是独立模块，不作为插件子类隐藏。

## 4. 信息架构

| 第一层模块 | 第二层上下文 | 主工作区 |
| --- | --- | --- |
| 主页 | 新聊天、搜索、置顶、项目 / 会话 | 当前对话 |
| 知识与记忆 | 团队知识库、项目知识、工作记忆 | 选中的知识内容或记忆 |
| 定时任务 | 全部任务、运行中、执行记录 | 任务详情 / 计划 |
| 插件 | 已安装、发现插件、更新 | 插件管理器 |
| 技能 | 已安装、发现技能、我的创作 | 技能管理器 |
| 供应链管理（身份业务插件示例） | 工作概览、供应商、采购订单、交付跟踪 | 对应业务页面 |
| 财务管理（身份业务插件示例） | 工作概览、应付管理、费用报销、经营报表 | 对应业务页面 |
| 账户头像（底部工具） | 设置弹框左侧分类 | 默认用户设置，弹框覆盖当前工作区 |

知识与记忆、定时任务与业务页面是用户确认的设计目标，并不表示仓库已有对应完整服务。原型使用示例导航与只读卡片；真实二级分类要结合能力核验，不能仅按原型宣称功能已上线。

业务入口可见条件：已安装 ∩ 已启用 ∩ 当前身份有访问权 ∩ 提供页面入口。此处是设计条件，待接入插件清单与权限服务；前端隐藏不能代替服务端权限校验。固定功能模块不混入身份业务区。

业务入口顺序优先使用企业配置的顺序，未配置时按显示名稳定排序；不按访问次数动态跳动。首版不引入自由拖拽。无可用业务时产品隐藏业务分组；原型保留“暂无业务”用于评审该状态。

## 5. 关键用户旅程

| 用户与目标 | 路径 | 风险与处理 |
| --- | --- | --- |
| 新用户开始任务 | 新聊天 → 保留当前项目上下文 → 输入 | 无项目时明确“未关联项目”，不自动绑定最近项目 |
| 多项目用户继续任务 | 展开项目 → 选择会话 → 主区显示所属项目 | 长标题省略，悬浮/聚焦提供全文；切换后保持列表位置 |
| 能力管理员 | 插件或技能 → 对应管理器 | 不合并入口；返回会话时恢复原会话与滚动位置 |
| 键盘用户定位内容 | 搜索聊天 → 输入 → 选择结果 → 返回 | Escape 关闭搜索并还焦；无结果保留查询和清除按钮 |
| 连接失败后恢复 | 侧栏错误提示 → 重试 → 恢复原树 | 不清除已有缓存，不把错误伪装成空项目 |

## 6. 视觉与组件规格

| 项目 | 规格 |
| --- | --- |
| 几何 | 固定模块窄栏 52px；上下文默认 280px、范围 264–420px；展开总宽默认 332px，收起后仅 52px。新几何需适配布局服务，不直接套用 v1 的 56/90px 单轨道规则 |
| 色彩（暗） | 侧栏 #202020；主区 #181818；悬浮 #2a2a2a；选中 #343434；主文字 #ededed；次文字 #ababab；边界 #383838 |
| 色彩（亮） | 侧栏 #f5f5f3；主区 #fff；悬浮 #eaeae7；选中 #e1e1dd；主文字 #222；次文字 #62625e |
| 排版 | 系统 UI 字体；品牌 17/24、600；行文字 14/20、400；分组 12/18、500 |
| 间距 | 基础 4px；左右内边距 12px；图标与文字 10px；分组上间距 20px |
| 行 | 模块按钮 40×40px，轨道宽 52px；上下文功能行 36px、项目行 34px、会话行 32px；圆角 8px；单行省略 |
| 图标 | 上下文 18px，模块轨道 21px；统一线宽 1.6–1.8；生产复用 Lucide |
| 选中 | 轨道表达当前模块，上下文表达当前页面/会话，可同时各有一个选中项；不把父项目画成会话选中 |

| 滚动 | 只有内容区主滚动；品牌、导航、底部固定；滚动条出现不改变文本宽度 |
| 动效 | 120–150ms；prefers-reduced-motion 禁用；不动画整棵树的尺寸 |

以上色值是提案参考，应映射到现有主题 token，避免在生产覆盖中引入另一套独立主题。普通文本对比度目标 4.5:1，图标和焦点 3:1；仍需对最终合成背景实测。

## 7. 交互与状态契约

- 项目开关是独立按钮，使用 aria-expanded；项目菜单、添加会话不嵌套在开关按钮内。当前会话使用 aria-current="page"；置顶会话在项目内用文字强调而不重复绘制第二个选中背景。
- 会话更多操作在 hover 或 focus-within 出现；触屏保持可发现入口。菜单支持 Escape、方向键及关闭后的焦点恢复。
- 搜索原型按会话标题过滤，并临时展开匹配项目；清空时恢复搜索前展开状态。生产搜索范围、索引及分页须在实现前确认。无结果区别于服务失败。
- 新聊天原型创建本地示例；真实产品在创建成功后才加入列表，失败保持原会话并提供重试。
- 加载使用骨架与 aria-busy，不显示“暂无项目”；无项目显示“添加项目”；空项目显示“在此项目开始聊天”；失败保留缓存并提供重试。
- 插件/技能页切换只改变主区面板，不清除会话数据；设置统一从账户头像打开模态弹框，移除独立设置按钮。
- 第一层模块轨道始终保留；只收起第二层上下文。顶栏展开按钮始终可达；收起时焦点转移至该按钮。模块切换保持用户当前的收起偏好；每个模块按钮有可访问名称、tooltip、选中背景与侧边标记。
- 初始窗口低于 1024px 时收起第二层，第一层保留；小于 700px 时手动展开第二层以覆盖方式呈现，顶栏按钮可关闭。生产需响应窗口 resize，保证主区最小宽度，并完善 Escape 关闭和焦点管理；原型仅演示初始收起和小窗覆盖布局。
- macOS 流量灯与拖拽区域、Windows 菜单与窗口按钮继续由桌面 shell 管理。原型是内容布局，未模拟原生窗口标题栏。
- 键盘操作使用现有快捷键注册表，先检测冲突；不在原型强抢浏览器全局快捷键。所有控件可 Tab / Shift+Tab，Enter/Space 激活。
- 账户头像弹框显示真实连接状态；错误区用 role=status 或 alert，不能只改变圆点颜色。

## 8. 工程落点与实施分期

1. 在桌面自有 client presentation 中实现双层侧栏组合与样式，并扩展布局服务区分 railWidth 与 contextWidth / contextCollapsed。主页上下文复用 `sidebar`、`sidebar.panellist`、`sidebar.workspaces`、`sidebar.settings` 和 `sidebar.footer.action` 插槽。先交付视觉与图标一致性，确保动态注册入口没有丢失。
2. 在产品包保留 `plugins` / `sensteed-skill-manager` 注册及兼容管理器逻辑；对品牌行和项目树逐步替换自有组件，不 fork 官方主前端。
3. 搜索、置顶、项目动作按现有服务能力接入；若缺公共契约，先评审契约。必须修改 Harness 时，仅在 sibling dev 上独立提交，桌面功能分支不直接修改 fork。
4. compatibility 模式继续运行默认 upstream client；新布局先面向 extended / advanced。Next 需独立评审，不自动镜像 Stable/Beta 变更。
5. 检查长标题、100+项目、1000+会话、第三方 footer、无账户、离线、字体缩放、平台窗口按钮。大列表按现有数据策略分页或虚拟化，不一次渲染所有后代。

工程评审待确认：项目/会话搜索 API、排序与置顶持久化、扩展入口分类元数据、窄窗焦点管理、是否需要可调整宽度的键盘替代操作。

招募 6 人（2 名新用户、2 名多项目用户、2 名插件/技能管理者），其中至少 1 人主要使用键盘。任务：创建项目会话、找回历史会话、区分插件与技能、窄窗恢复会话、错误后重试。记录完成率、耗时、错误数及 SUS；目标核心任务完成率 >85%、定位既有会话中位数 <15 秒、SUS >80。以上为目标，不是测试结果。

实施前进行 6 人树测试；严重问题按 S1 阻断 / S2 明显受阻 / S3 轻微摩擦记录，S1 清零后再进入开发验收。本轮未开展参与者测试、工程签字或生产视觉回归。

## 10. 模块状态与身份切换规则（v2）

- 模块切换保留各自最近页面、上下文滚动、展开项和查询；主页返回原会话。原型演示页面和滚动恢复，状态只保留在当前浏览器页面生命周期内。生产需要按用户 / 企业 / 模块隔离状态，禁止跨身份泄露缓存。
- 同一身份的业务入口暂时卸载或失去权限时，若正在访问，立即停止展示该内容并返回主页，显示原因；移除所有可访问的深链入口。原型用顶部演示身份模拟入口更新与安全回退。
- 切换身份时应取消旧身份请求、清空或隔离敏感缓存，并由服务端重新授权；原型示例数据不涉及敏感信息，不充当鉴权实现。生产默认回到新身份主页，再恢复该身份自己的状态。
- 权限加载中不展示上个身份的业务入口；失败时显示重试、固定基础模块仍可用。连接错误与权限拒绝分开提示。普通成员无业务模块时不显示空分隔线。
- 插件注册需明确 id、label、icon、入口、order 和访问状态，复用现有插件能力；字段及权限契约待评审。业务图标缺失时使用拼块回退并保留名称，不能显示破图。
- 设置统一由账户头像打开模态弹框，默认用户设置页。关闭不改变模块、会话、查询、滚动或第二层展开状态。弹框顶部系统操作在原型内禁用，退出仅显示说明，不执行真实操作。

新增验收：管理员看到两个示例业务模块；供应链专员仅见供应链；财务专员仅见财务；普通成员无业务入口；当前模块失权后回到主页。依次切换主页 → 供应链供应商 → 财务费用报销 → 主页，应恢复会话；返回两个业务模块应分别恢复供应商与费用报销。第二层收起时仍可切换所有模块。

## 11. 头像设置弹框与悬浮提示（v3）

- 用户确认：窄栏压缩到 52px；按钮 40×40px，左右各 6px。底部只保留头像，不保留齿轮按钮。原生窗口安全区域仍由 shell 管理。
- 所有可交互图标按钮在悬浮或聚焦 250ms 后出现提示：全局模块、业务模块、头像、上下文开关、新聊天、搜索与弹框关闭。提示通过视口级浮层绘制，避免被轨道滚动容器裁剪；移开、失焦、滚动、点击或 Escape 关闭。图标按钮保留可访问名称，提示使用 role=tooltip / aria-describedby。装饰图标不添加冗余提示。
- 头像打开模态设置弹框，参考用户截图的左分类 / 右内容布局。默认用户设置，分类包含通用设置、模型设置、内置能力、内置插件、Agent 预设、IM 机器人、桌面。分类为导航按钮，原型只展示配置占位，不伪造可保存配置。正式接入需核对可用设置分类及图标，避免重复桌面入口。
- 用户页展示当前账号、企业身份、默认模型、内置能力；示例不复制截图中的真实账号信息。顶部打开配置、诊断、终端、重启按钮展示为禁用态，避免误认为已连接桌面服务。
- 使用原生 dialog.showModal 提供背景隔离与焦点约束，打开后聚焦关闭按钮，关闭后还焦头像；支持关闭按钮、Escape 与点击遮罩关闭。不能因弹框开关清除当前工作上下文。
- 桌面弹框最大宽 1100px、高 820px，四周至少留 32px/40px；窄屏缩小内边距并允许内容独立滚动。深浅主题保持一致。
- 新增验收：每个图标悬浮出现完整名称且不裁切；滚动后提示消失；底部无设置齿轮；头像弹框默认用户设置；Tab 不进入背景；分类切换有效；三种关闭方式均恢复头像焦点与原模块；亮色与窄窗均可访问关闭按钮。

## 12. 跨插件落地（第二阶段）

业务模块通过 `desktop.navigation.context` keyed/root 插槽提供实际目录与路由动作，复用各插件自身权限过滤和离页确认。契约与身份边界详见 [业务导航契约](business-navigation-contract.md)，当前完成状态及剩余人工验收见 [实施记录](sidebar-implementation.md)。本轮没有新增模拟业务页面，也没有修改 Harness 或启动发布流程。
