# 侧栏重设计产品规格

日期：2026-10-19 · 版本：v1 · 负责人：产品设计提案 · 状态：待评审

## 1. 目标与范围

让侧栏成为稳定的工作入口：快速开始对话、返回项目上下文、发现插件与技能、理解任务状态。视觉参考 Codex 的低饱和深色侧栏、轻量行选中、紧凑项目树，保留 Sensteed 品牌。

本轮交付独立 HTML 高保真原型和实现规格。原型没有连接账户、工作区、插件服务或对话服务；产品中的所有真实操作仍需后续实现。本轮不启动桌面应用、不触发打包。

## 2. 现状证据与假设

| 来源 | 已确认事实 | 设计影响 |
| --- | --- | --- |
| 用户提供的 Codex 截图 | 项目与子会话形成树；选中项用灰底；外围还有全局图标轨道 | 复用层级与灰阶语言；不机械增加第二条图标栏 |
| `dsh-sensteed-product/src/client/register-hub-pages.tsx` | 插件使用 Blocks，技能使用 Sparkles，均注册 sidebar.panellist | 两个入口始终独立；保持现有 panel id 和旧管理页优先逻辑 |
| `dsh-plugin-desktop/src/client/layout-state.ts` | 默认 280px，范围 264–420px；普通轨道 56px，增强 macOS 90px；1024px 自动收起 | 默认稿采用 280px；实现保留平台差异，原型仅演示 56px 轨道 |
| `dsh-plugin-desktop/src/client/sidebar-footer-styles.ts` | 底部扩展入口存在专门的纵向排列与溢出处理 | 不移除第三方入口；有限高度下可滚动且不能挤掉项目区 |
| Harness `packages/client/ui-sidebar/src/client/SidebarRoot.tsx` | 全局导航、项目区、设置和 footer 有分离插槽；已有 aria-current 和收起渐隐 | 沿用插槽及状态服务，不靠 DOM 选择器重排业务节点 |

尚未收集真实用户访谈、行为分析或当前运行时截图。以上是代码观察与参考截图，不能充当技能流程要求的三条用户数据。项目树可发现性、插件/技能辨识度与底部拥挤是待验证假设。信息架构尚未进行卡片分类或树测试，工程可行性也未正式签字。

## 3. 设计决策

采用单侧栏，而不是同时常驻外层轨道和宽列表。展开态用图标加文字保证识别；收起态才展示图标轨道，减少横向空间消耗。

品牌行、快捷导航、内容树、账户工具分四区。将插件与技能固定在内容树上方，避免项目列表变长后消失。用拼块表示插件，用星芒表示技能，用齿轮表示设置；禁止三个入口共用通用网格图标。

新聊天保持轻量行按钮，不使用大面积品牌色。主要视觉焦点留给当前会话。当前会话用灰色圆角背景及较亮文字；运行中用旋转环并配可访问文本，完成未读用小圆点；颜色不单独承载状态。

## 5. 关键用户旅程

| 用户与目标 | 路径 | 风险与处理 |
| --- | --- | --- |
| 新用户开始任务 | 新聊天 → 保留当前项目上下文 → 输入 | 无项目时明确“未关联项目”，不自动绑定最近项目 |
| 多项目用户继续任务 | 展开项目 → 选择会话 → 主区显示所属项目 | 长标题省略，悬浮/聚焦提供全文；切换后保持列表位置 |
| 能力管理员 | 插件或技能 → 对应管理器 | 不合并入口；返回会话时恢复原会话与滚动位置 |
| 键盘用户定位内容 | 搜索聊天 → 输入 → 选择结果 → 返回 | Escape 关闭搜索并还焦；无结果保留查询和清除按钮 |
| 连接失败后恢复 | 侧栏错误提示 → 重试 → 恢复原树 | 不清除已有缓存，不把错误伪装成空项目 |

## 6. 视觉与组件规格

| 项目 | 规格 |
| --- | --- |
| 几何 | 展开默认 280px，最小 264px，最大 420px；沿用现有布局服务 |
| 色彩（暗） | 侧栏 #202020；主区 #181818；悬浮 #2a2a2a；选中 #343434；主文字 #ededed；次文字 #ababab；边界 #383838 |
| 色彩（亮） | 侧栏 #f5f5f3；主区 #fff；悬浮 #eaeae7；选中 #e1e1dd；主文字 #222；次文字 #62625e |
| 排版 | 系统 UI 字体；品牌 17/24、600；行文字 14/20、400；分组 12/18、500 |
| 间距 | 基础 4px；左右内边距 12px；图标与文字 10px；分组上间距 20px |
| 行 | 功能行 36px；项目行 34px；会话行 32px；圆角 8px；单行省略 |
| 图标 | 常规 18px，轨道 20px；统一线宽 1.6–1.8；生产复用 Lucide |
| 选中 | 功能页与会话互斥表达主面板；所属项目保留展开，不把父项也画成选中 |
| 焦点 | 2px #9cbfff 外描边，2px offset；不能以 hover 替代 focus-visible |
| 滚动 | 只有内容区主滚动；品牌、导航、底部固定；滚动条出现不改变文本宽度 |
| 动效 | 120–150ms；prefers-reduced-motion 禁用；不动画整棵树的尺寸 |

以上色值是提案参考，应映射到现有主题 token，避免在生产覆盖中引入另一套独立主题。普通文本对比度目标 4.5:1，图标和焦点 3:1；仍需对最终合成背景实测。

## 7. 交互与状态契约

- 项目开关是独立按钮，使用 aria-expanded；项目菜单、添加会话不嵌套在开关按钮内。当前会话使用 aria-current="page"。
- 会话更多操作在 hover 或 focus-within 出现；触屏保持可发现入口。菜单支持 Escape、方向键及关闭后的焦点恢复。
- 搜索原型按会话标题过滤，并临时展开匹配项目；清空时恢复搜索前展开状态。生产搜索范围、索引及分页须在实现前确认。无结果区别于服务失败。
- 新聊天原型创建本地示例；真实产品在创建成功后才加入列表，失败保持原会话并提供重试。
- 加载使用骨架与 aria-busy，不显示“暂无项目”；无项目显示“添加项目”；空项目显示“在此项目开始聊天”；失败保留缓存并提供重试。
- 插件/技能页切换只改变主区面板，不清除会话数据；设置独立页面或现有面板，避免含义不明的相同图标。
- 收起轨道保留新聊天、搜索、插件、技能、展开项目、设置、账户；每个按钮有可访问名称与延迟 tooltip。点击项目入口先展开，再还焦项目区。
- 内容宽度低于 1024px 沿用自动收起；用户临时展开时保证可关闭。移动/窄窗覆盖层及焦点陷阱待工程细化，不用缩小整页字体处理。
- macOS 流量灯与拖拽区域、Windows 菜单与窗口按钮继续由桌面 shell 管理。原型是内容布局，未模拟原生窗口标题栏。
- 键盘操作使用现有快捷键注册表，先检测冲突；不在原型强抢浏览器全局快捷键。所有控件可 Tab / Shift+Tab，Enter/Space 激活。
- 账户行显示真实连接状态；错误区用 role=status 或 alert，不能只改变圆点颜色。

## 8. 工程落点与实施分期

1. 在桌面自有 client presentation 中实现侧栏组合与样式，复用 `sidebar`、`sidebar.panellist`、`sidebar.workspaces`、`sidebar.settings` 和 `sidebar.footer.action` 插槽。先交付视觉与图标一致性，确保动态注册入口没有丢失。
2. 在产品包保留 `plugins` / `sensteed-skill-manager` 注册及兼容管理器逻辑；对品牌行和项目树逐步替换自有组件，不 fork 官方主前端。
3. 搜索、置顶、项目动作按现有服务能力接入；若缺公共契约，先评审契约。必须修改 Harness 时，仅在 sibling dev 上独立提交，桌面功能分支不直接修改 fork。
4. compatibility 模式继续运行默认 upstream client；新布局先面向 extended / advanced。Next 需独立评审，不自动镜像 Stable/Beta 变更。
5. 检查长标题、100+项目、1000+会话、第三方 footer、无账户、离线、字体缩放、平台窗口按钮。大列表按现有数据策略分页或虚拟化，不一次渲染所有后代。

工程评审待确认：项目/会话搜索 API、排序与置顶持久化、扩展入口分类元数据、窄窗焦点管理、是否需要可调整宽度的键盘替代操作。

## 9. 验收与测试计划

| 场景 | 验收标准 |
| --- | --- |
| 入口发现 | 展开态插件、技能独立可见，图标语义不同；均最多一次激活到管理页 |
| 列表压力 | 900px 高度下主要导航和账户不被项目滚走；footer 不吞掉整个工作区 |
| 会话切换 | 标题、项目上下文、选中状态一致，列表位置保留；运行状态有文本等价物 |
| 搜索 | 有结果、无结果、失败、清除、返回分别可操作；清除后还原展开状态 |
| 折叠 | 56px / macOS advanced 90px 分别检查；每个入口可键盘访问且有提示 |
| 无障碍 | 正文 4.5:1；焦点清晰；放大 200% 后可滚动；减少动态效果生效 |
| 回归 | 模式切换、插件动态注册、旧管理器优先、品牌变体及窗口控件无回归 |

招募 6 人（2 名新用户、2 名多项目用户、2 名插件/技能管理者），其中至少 1 人主要使用键盘。任务：创建项目会话、找回历史会话、区分插件与技能、窄窗恢复会话、错误后重试。记录完成率、耗时、错误数及 SUS；目标核心任务完成率 >85%、定位既有会话中位数 <15 秒、SUS >80。以上为目标，不是测试结果。

实施前进行 6 人树测试；严重问题按 S1 阻断 / S2 明显受阻 / S3 轻微摩擦记录，S1 清零后再进入开发验收。本轮未开展参与者测试、工程签字或生产视觉回归。
