## 当前实现与完整设计的差异

1. **业务二级导航仍由真实业务页面提供。** 财务、供应链、知识插件未提供可供外部切换的统一导航契约。当前上下文列显示模块标题与返回主页入口，业务操作继续位于主工作区。原型中的“供应商 / 采购订单”等分类尚未迁入独立上下文列；不能把没有真实路由的按钮加入产品。
2. **知识与记忆按真实插件可用性出现。** 不可用时不创建虚假的固定页面。现有第三方 footer 入口按注册顺序保留，其自身组件决定是否有权显示；桌面层不推断组织角色。
3. **跨身份缓存隔离和主动失权回退仍由插件负责。** 本轮保留现有服务端鉴权与客户端可见性判断；入口卸载回退不等于完成全产品身份切换协议，不能将前端隐藏视为安全验收。
4. **业务页内部状态恢复未作统一保证。** 主页项目树维持挂载；业务页仍遵循原页面生命周期和自身持久化机制。后续需通过导航契约按身份隔离并保留各模块的位置。
5. **人因和平台实机验证待执行。** 未开展六人树测试、SUS 测试、真实企业权限矩阵验证、macOS/Windows 窗口控件实机验收及 200% 缩放完整验收。
