## 当前实现与完整设计的差异

1. **业务二级导航已接入。** 供应链、财务、知识通过可选 keyed 上下文插槽公开真实目录，侧栏和主页面共同使用插件路由动作。财务的未保存 / 忙碌确认继续有效，未知或未授权路由不能被桥接选择。没有该插槽时，插件仍显示独立页面导航。
2. **入口以真实访问权限为准。** 知识和供应链补上 access 探测，财务沿用原探测；待确认时不显示入口，确认撤销后隐藏并返回主页。暂时连接故障不等于服务端撤销同一身份的既有许可。
3. **身份和旧响应边界已实现。** 无 payload 的身份变化事件清理导航和缓存；宿主随机 scope 回执及客户端 epoch / AbortSignal 防止旧响应进入新身份。已拒绝的 bridge 不能被旧 publish 或 remember 恢复。普通客户端的旧覆盖页面也会在身份变化时关闭。
4. **同身份位置恢复已实现。** 供应链和知识保留最近分类，财务保留路由/筛选/视图状态及离开时滚动位置；上下文目录保留滚动，知识保留查询和筛选。身份变化清空上述状态，不保存接口结果或未提交表单。大量项目和会话仍复用原项目树实现，尚未宣称完成新的性能压测。
5. **真实数据和人工验证仍待执行。** 六人树测试、SUS、四类真实企业账号权限矩阵、macOS/Windows 窗口实机和 200% 缩放验收尚未完成。隔离 API fixture 的浏览器测试不代替真实账号验收。
