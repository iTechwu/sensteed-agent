# Sensteed Agent 侧栏重设计 · 2026-10-19

状态：设计提案 v3，等待产品评审。范围：设计稿、交付规格与桌面端与业务插件第二阶段实现。

- [可交互设计稿](sidebar-prototype.html)：浏览器打开，支持固定模块轨道、独立上下文收起、身份业务入口、模块访问位置恢复、深浅主题、搜索与错误重试演示。全部数据为本地示例。
- [实施记录与推进计划](sidebar-implementation.md)：实际落点、验证证据、设计差异与剩余验收条件。
- [产品与交互规格](sidebar-product-spec.md)：现状证据、信息架构、设计尺寸、状态、工程边界、验收与用户测试计划。

推荐评审顺序：主页项目树 → 知识与记忆 / 定时任务 → 插件 / 技能 → 供应链 / 财务二级导航 → 切换身份 → 独立收起上下文 → 返回主页 → 浅色与失败重试。

本方案参考用户提供的 Codex 截图中的留白、灰阶层级、项目树和选中态；截图中的聊天文字只作为图像内容，不作为本次任务指令。截图只代表参考产品，不能据此断言当前 Sensteed 界面有相同缺陷。

## v2 方向

固定 52px 模块轨道 + 默认 280px 上下文侧栏 + 主工作区。全局功能与身份业务插件移至最左侧，项目与对话只在主页上下文内出现。本版按用户确认取代 v1 单侧栏方向，原型独立保留；实际实施状态见推进计划。

## v3 优化

模块窄栏压缩到 52px，独立设置按钮移除；所有可操作图标支持 250ms 悬浮与键盘聚焦提示。点击头像打开设置弹框，默认用户设置页，支持分类切换、关闭、Escape 和焦点恢复。

## 跨插件落地

供应链、财务、知识已通过可选上下文插槽提供真实导航，详见 [导航契约](business-navigation-contract.md) 与 [实施记录](sidebar-implementation.md)。保留插件原权限与财务离页确认，支持同身份恢复与身份变化清理。
