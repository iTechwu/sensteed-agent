# 本地安装 App 的三轮体验审查

用户要求：每轮重新本地打包、安装、逐页审查，再根据体验发现优化并进入下一轮。本记录区分安装包、实际审查、代码修复和外部依赖，不以“页面能打开”代替任务体验通过。

## 验收方式

- 每轮通过仓库 tag 发布门禁构建目录 App，退出上一实例后安装到 `/Applications/Sensteed-Agent Beta.app`；比对源与安装副本的 app.asar SHA256，保留旧包回退。
- 通过原生 App 的可访问性树、截图、实际导航、搜索、表单校验和控制台进行启发式审查。
- 页面范围：主页和聊天三个视图、自动化、插件目录/内置能力、技能目录/本地技能、知识九页、财务概览及26个入口、供应商六页、设置八类。
- 关注用户目标：找到功能、理解数据状态、有效输入、清楚反馈、错误恢复、跨页连续性、键盘操作。
- 真实财务提交/审核、知识写入、外部消息和插件安装不在企业身份下制造测试数据；可撤销的页面搜索与未提交输入用于体验验证。
- 这属于专家审查与实际 App 验证，没有招募用户，未虚构 SUS 或任务成功率。

## 体验问题闭环

| 问题 | 首次发现 | 最终验证 |
|---|---|---|
| 技能长说明影响浏览、筛选缺数量与恢复 | 第一轮 | 结果数量、渐进披露、清除搜索和键盘回车路径通过 |
| 无效 JSON 无就地提示且会退为默认配置 | 第一轮 | 类型校验、字段错误与禁用提交通过；未提交生产配置 |
| 图谱维护误占主操作层级 | 第一轮 | 独立折叠任务，日常读取优先 |
| 比较字段缺可见标签、单个版本出现试算提示 | 第一轮 | 基准/对比标签、提示触发条件通过 |
| 收起资源栏仍有不可见控件 | 第一轮 | 实际打开/关闭后，关闭区域控件移除 |
| 多个治理任务共享草稿字段 | 第二轮 | 来源/空间、导入/提升、记忆/导入实测隔离；两种授权输入回归隔离 |
| 供应链失败裸露服务代码 | 第二轮 | 已知连接错误提供中文恢复说明，回归通过 |
| 服务不可用被当成撤权并退回主页 | 第三轮 | 修正版连续切页与跨模块返回稳定；连接故障保留/403清理回归通过 |

- 冷启动 Host 阶段的耗时问题仍保留，未以本轮导航与表单优化冒充性能问题已解决。
- 此前预算比较接口曾有 400；本轮最终巡检未再观察到，但未覆盖全部版本与年度组合，因此不宣称后端比较契约已完整修复。
- 外部供应链服务仍可能不可用，本轮改善失败状态、重试和位置保留，不能保证远端服务可用性。
- 未在真实企业身份下执行提交、审核、授权变更、插件安装或对外消息；不是这些流程的生产写入验收。
