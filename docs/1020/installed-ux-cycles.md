# 本地安装 App 的三轮体验审查

用户要求：每轮重新本地打包、安装、逐页审查，再根据体验发现优化并进入下一轮。本记录区分安装包、实际审查、代码修复和外部依赖，不以“页面能打开”代替任务体验通过。

## 验收方式

- 每轮通过仓库 tag 发布门禁构建目录 App，退出上一实例后安装到 `/Applications/Sensteed-Agent Beta.app`；比对源与安装副本的 app.asar SHA256，保留旧包回退。
- 通过原生 App 的可访问性树、截图、实际导航、搜索、表单校验和控制台进行启发式审查。
- 页面范围：主页和聊天三个视图、自动化、插件目录/内置能力、技能目录/本地技能、知识九页、财务概览及26个入口、供应商六页、设置八类。
- 关注用户目标：找到功能、理解数据状态、有效输入、清楚反馈、错误恢复、跨页连续性、键盘操作。
- 真实财务提交/审核、知识写入、外部消息和插件安装不在企业身份下制造测试数据；可撤销的页面搜索与未提交输入用于体验验证。
- 这属于专家审查与实际 App 验证，没有招募用户，未虚构 SUS 或任务成功率。
