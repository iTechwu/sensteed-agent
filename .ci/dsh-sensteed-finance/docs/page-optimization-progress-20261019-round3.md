# 财务页面剩余优化：2026-10-19 第三轮

承接 [第二轮剩余清单](page-optimization-progress-20261019-round2.md)，本轮集中成本工程的供应商报价、报价登记与 EBOM 导入。交付为源码与本地验证；未触发 Jenkins、线上部署或桌面发布。

## 已完成的两端对照

| 页面 / 操作 | 原有差异 | 本轮结果 |
| --- | --- | --- |
| 供应商报价台账 | 插件无检索、无分页；网页整表滚动 | 均按零件号、供应商、批次检索，每页 20 条，显示总数与页码。检索回首页，刷新后总页数减少时钳制当前页。 |
| 报价单价 | 网页将外币显示成人民币符号，四位报价只显示三位；插件标题一律“元” | 两端均采用“单价 + 原币种”，保留最多四位小数；不会把 USD 当作人民币。登记字段明确使用所选币种。 |
| 报价采用入口 | 插件允许点开过期、外币、无编号报价；网页按钮禁用但原因不完整 | 统一“用于预测”，在禁用按钮旁解释草稿、零件号、币种或有效期原因；未知/无效有效期也阻止采用。只读仍可查看原因。 |
| 有效期 | 网页仅在组件挂载时取一次当前时间 | 台账每 30 秒更新显示；点开、预览、确认时重新检查有效期。预览期间过期会清除预览并阻止提交。服务端继续负责最终权限、包状态、有效期及并发校验。 |
| 报价登记表单 | 网页多数输入仅有 placeholder，错误只出 toast；插件已有通用错误定位 | 网页补上常驻标签、必填标识、本地时间说明、字段错误关联及首错聚焦；错误就近显示，失败保留输入。两端币种三字母、报价四位小数及可选项说明一致。网页增加提交锁，防止重绘前连点重复登记。 |
| 报价采用表单 | 插件缺常驻字段标签，计价/分项含义与网页不同 | 标题、确认动作、计价/分项说明及供应商人工提示对齐；保留明确选择位置→预览→确认。未匹配位置给出原因，不默认选位置。 |
| 插件 EBOM 导入失败 | 写入失败清空预览，只能重新上传 | 保留全部预览、搜索、页码，显示错误后可重试；请求锁防连点。选择新文件时仍清除上一份预览。 |
| 插件 EBOM 核对 | 缺原表行号、所有导入都强制勾选，全部重复也能确认；无取消预览 | 原表行号与网页一致按服务端 sort + 2 展示；有警告才要求确认，全部位置已存在时禁用导入并解释；补充“取消预览”。确认始终提交全部预览行，不仅当前页或检索结果。 |

- 插件 `npm run check`：构建、语法与 **216 项测试通过**。新增 45 条台账跨页/检索/刷新、禁用原因、原币种精度；25 行 EBOM 的翻页、原表行号、写入失败保留、请求锁及免重传重试。

- 浏览器加载两端真实组件源码，采用本地虚构数据和模拟请求。实际操作 45 条报价翻页、跨页检索第 45 条、网页空表单定位、登记失败保留输入；插件预览 25 行→第二页→检索原表第 26 行→导入失败→保留并再次提交。模拟服务返回行号错误只验证显示与保留行为，不证明真实 Excel 解析或生产写入成功。
