## 统一口径

- 预算超支只比较预算行的已打 PR 与预算；未发布预算不能输出“无超支”。
- 未知预计余额不使用实际余额或收支净额替代；部分缺失时不能排除整个范围的资金缺口。
- 部分收支字段缺失时不计算达成率及净流入；缺失金额不解释为零。
- 数据质量检查覆盖当前团队全部年度与主体；问题数量允许重复命中，不能当作去重行数。
- 页内问答只读取既有公开业务契约；深度分析仍使用现有宿主新会话桥接。没有新增模型调用、MCP 入口或认证旁路。
- 问答计算权威实现位于 Datasource `assistant-answer.ts`，插件同步在 `src/views/assistant-answer.js`；修改任一端后运行 `npm run check:datasource`，直接执行两端计算函数做结果对照。
