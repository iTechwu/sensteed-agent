# 财务页面剩余优化：2026-10-19 第六轮

承接[第五轮剩余清单](page-optimization-progress-20261019-round5.md)，本轮完成预算退回、复制下一轮预算与明确历史填报人的表单对齐。Datasource 提交 `1f126f7` 已推送 main；插件源码、构建产物与本记录一并提交。未执行 Jenkins、生产部署或桌面发布。

## 本轮逐项对照

| 页面 / 操作 | 原有差异或缺陷 | 本轮结果 |
| --- | --- | --- |
| 退回预算条目 / 部门预算 | 空原因静默禁用，错误无法定位，关闭会丢失原因 | 两端统一去除首尾空白后的 1 至 500 字校验、字段错误与聚焦。显示年度、部门、预算版本，以及条目费用 / 月份 / 金额 / 说明或部门合计；取消、关闭、Escape 和遮罩经未保存确认。 |
| 复制下一轮预算 | 网页依赖原生校验、调整原因是单行；插件只显示汇总错误 | 两端常驻必填标签，调整原因改为多行，提交时标记全部错误并聚焦首错；名称 1 至 150 字、原因 1 至 500 字。展示范围、新名称、当地截止时间、已明确历史填报人数，以及“仍为草稿，须到填报活动发布”。 |
| 截止时间 | 直接转换可能将无效日历日期进位或丢失错误位置 | 严格验证当地日期与时分，拒绝日历进位和夏令时缺失时刻，合法值才转为 ISO。保留当地输入语义；是否允许当前时间窗口继续由服务端裁定。 |
| 明确历史预算填报人 | 网页未逐字段校验；缺少受影响条目与结果摘要 | 两端共用各自复制轮次的表单流程，展示费用、月份、金额、说明、所选人员与“恢复草稿，须重新审批”。只提交当前条目的 ID、原 revision 与所选用户 ID。 |
| 组织人员选择 | 旧选项可能在目录失效后被提交，复制表单缺少目录错误入口 | 只允许有用户 ID、已启用、非 LOCAL_MIRROR 的目录成员。加载、失败、无成员阻止提交，目录可重试；目录刷新后不再可用的旧选择会成为字段错误。部门归属最终仍由服务端判定。 |
| 请求与退出 | 复制、责任人等流程可能重复提交或丢失填写 | 本地状态与同步锁共同阻止重绘前重复请求和关闭；失败保留全部原文及选择，显示业务原因。继续编辑保留内容，明确放弃才退出；选择后清空不会误判为未保存。保留浏览器刷新 / 关闭保护。 |
| 共用人员组件 | 预算选择人员仍提示“配置权限”，错误缺少可访问关联 | 网页人员选择器新增可选字段名、错误状态及说明关联；通用提示改为“即可选择”。既有调用默认行为保持兼容。 |

网页继续使用既有 Dialog 和组织人员选择器，插件继续使用桌面组件；本轮统一业务认知、输入和反馈，没有修改权限、审批规则、后端请求契约、页面路由或 MCP 边界。
