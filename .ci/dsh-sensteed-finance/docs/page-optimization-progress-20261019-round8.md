# 财务页面剩余优化：2026-10-19 第八轮

承接[第七轮剩余清单](page-optimization-progress-20261019-round7.md)，本轮完成网页端与财务插件的跨页面离开保护收敛，重点处理年度 / 组织筛选、侧栏和内部路由、成本包切换，以及请求处理中状态。未执行 Jenkins、生产部署或桌面发布。

## 本轮逐项对照

| 页面 / 操作 | 原有差异或缺陷 | 本轮结果 |
| --- | --- | --- |
| Datasource 全局导航 | 网页端表单只保护弹窗自身的关闭，侧栏、年度切换和同源链接可能绕过未保存确认 | App Shell 提供统一导航守卫；所有财务录入会话登记 dirty / busy / discard 状态，同源链接、侧栏和工作台内部动作统一进入离开检查。外站、下载、新标签、带修饰键点击和当前页锚点保持浏览器原行为。 |
| Datasource 年度 / 组织 / 分页 | 切换工作台年份、版本、组织或分页时，脏内容可能被直接替换 | 预算填报、审批和版本分页动作通过统一 leave；确认放弃后才切换，所有登记会话一次性清理。 |
| Datasource CE 成本包 | 成本包选择会替换当前上下文，未接入统一表单保护 | 成本包选择接入导航守卫，和报价、EBOM 导入预览使用同一套离开语义。 |
| Datasource 保存中状态 | 保存、批量写入或目录提交期间，离开确认可能误放行或重复清理 | 录入弹窗、雇佣记录、权限策略和恢复策略登记 busy；处理中显示“正在处理，请稍候”，不允许切换或关闭，并继续保留浏览器 beforeunload 防护。 |
| Sensteed 财务插件 | 插件侧栏、年份、组织、刷新、返回和关闭依赖单一 EntryPanel 回调，其他页面容易绕过保护 | 工作台建立全局 navigation guard，入口页面统一登记 dirty / busy；侧栏、年份 / 组织、刷新、返回、成本录入和关闭都经同一个 leave。插件提示文案与网页端保持一致。 |
| 双端确认语义 | 两端确认按钮和导入预览说明不同，用户需要重新理解 | 统一为“继续填写 / 放弃并继续”，明确说明填写或导入预览会被清空；请求处理中使用独立阻塞提示，不把忙状态误报成脏数据。 |

## 验证与边界

- Datasource `pnpm quality:gate`：文档状态、架构、模板烟测、API / Web 类型检查全部通过，6 项任务成功。
- Datasource 导航守卫专项回归：**23 项测试通过**，覆盖多表单一次确认、取消 / 放弃、已还原表单不提示、请求处理中阻止、beforeunload，以及外站 / 下载 / 新标签 / 锚点 / 修饰键链接保留原行为。
- Sensteed 财务插件 `npm run check`：**230 项测试通过**，覆盖工作台入口、财务录入脏退出、处理中锁定和现有预算 / 权限 / CE 回归。
- 本轮仅调整客户端导航与状态登记；没有修改 MCP 路由、认证、服务端权限裁定或数据写入契约。
