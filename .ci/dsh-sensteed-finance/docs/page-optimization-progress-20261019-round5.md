## 本轮逐项对照

| 页面 / 操作 | 原有差异或缺陷 | 本轮结果 |
| --- | --- | --- |
| 金额输入 | 网页每次输入立即转数字，清空、尾零等编辑状态丢失 | 两端保留输入原文，`1250.50` 在修改和失败后保持原样；保存时再转契约数值。统一金额大于零、上限及最多两位小数，月份为 1 至 12 月，说明为去除首尾空白后的 1 至 500 字。 |
| 必填与错误 | 两端错误集中在末尾；网页原生校验与业务提示混用 | 常驻必填标签，提交时同时标记无效字段、关联说明并聚焦首错。修正后就地更新错误，未通过校验不发送请求。 |
| 年度费用映射 | 配置型表单需要防止跨类别映射与陈旧选项 | 保留年度配置与本部门映射快照；一级类别变化清空下游，二级仅展示所属选项。未导入配置、无映射或无费用类别时明确说明并禁止保存。 |
| 保存前认知 | 缺少年度 / 部门 / 版本和金额摘要 | 两端显示同一范围、费用科目与分类、月份、两位小数金额，以及“保存后仍为草稿，提交后进入初审”。 |
| 取消 / 关闭 | 修改后直接取消会丢失输入 | 取消、关闭按钮、Escape 和遮罩经未保存确认，可继续填写或明确放弃；脏表单保留浏览器刷新 / 关闭保护。网页复用既有轻量 guard，插件复用通用表单退出保护。 |
| 保存期间与失败 | 不能只依赖异步 mutation 重绘来锁定操作 | 本地状态与同步请求锁共同防止重复保存和关闭；失败保留输入、条目 ID 与 revision，显示业务原因供核对与重试。成功仍由既有保存流程关闭、刷新。 |
| 小窗口与搜索 | 网页长弹窗在 640 高度时超出屏幕；插件搜索提示缺字段语义 | 网页预算编辑弹窗限制 90dvh 并内部滚动。插件保留已有滚动容器；通用可搜索选项提示携带字段名，搜索框明确为“搜索费用科目与分类”等。 |

两端继续使用各自现有组件体系；本轮统一业务步骤、输入规则和结果反馈，没有重建页面容器或改变预算审批规则。
