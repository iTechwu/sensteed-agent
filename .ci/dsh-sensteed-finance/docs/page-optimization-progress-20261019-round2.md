# 财务页面剩余优化：2026-10-19 第二轮

承接 [上一轮清单](page-optimization-progress-20261019.md)。本轮是源码交付和本地受控验收，两个仓库均已提交并推送；未触发 Jenkins、网页部署或 Sensteed 桌面发布。

## 已完成

| 页面 / 流程 | 问题 | 本轮结果 |
| --- | --- | --- |
| 年度对比：默认版本 | 插件无主版本时直接选择第一条，可能选中草稿 | 两端统一为主版本 → 已发布版本 → 第一条。仍可手动选草稿，明确展示试算。 |
| 年度对比：版本选择 | 网页刷新查询会重置手选；只提示目标草稿，不提示基准草稿或已确认未发布版 | 刷新保留当前有效选择，版本失效后回退；任一侧为 DRAFT / CONFIRMED 均提示“试算比较”。改变目标年度不重置基准选择。 |
| 年度对比：指标 | 网页差额及表尾包含单侧项目，变化率却只按可比项目计算 | 差额、变化率及表尾合计统一采用两年均存在的项目。年度总额仍展示全部项目，并说明区别。新增项目单列，不参与同比。真实零金额仍可比较。例：100→120，加新增900，年度目标总额1020，可比变化+20（+20%），表尾100→120。 |
| 年度对比：认知 | 网页同年同类型版本难区分，费用类别暴露英文枚举 | 使用已有统一版本文案，包含名称、年度、类型、状态、明细与金额；费用类别采用既有中文业务标签。 |
| 插件比较、全面预算 | 返回后版本、参数批次与结果批次被挂载重置 | 返回恢复对比年度、两侧选择、编制版本、参数及计算批次；重新读取当前服务端数据。不恢复发布、计算等写入弹窗。 |
| 插件审核、权限历史 | 返回后类别、筛选和页码丢失 | 审核恢复类别与页码；权限页恢复人员/岗位页签，历史成员、功能、有效期筛选及分页。审批勾选、审批回执和写入表单不缓存。 |
| 通用单表 / 多行表单 | 错误只有底部文字或依赖浏览器原生必填；自定义选项缺少一致校验 | 必填、数字范围、选项失效、文本长度及日期统一检查；字段显示错误并关联 aria-describedby / aria-invalid；提交定位首错，多行提示出错行。条件隐藏字段不校验、不提交；0 不当成空值。 |
| 通用表单关闭 | 改过内容直接取消或 Escape 会丢失 | 取消、关闭按钮、遮罩与 Escape 统一检查未保存；提示“继续编辑 / 放弃修改并关闭”，自动聚焦继续编辑，返回原焦点。刷新/关闭窗口沿用浏览器 beforeunload 提示。请求期间禁止关闭与重复提交；失败保留输入。 |
| 全面预算：准备度 | 缺失统计显示 undefined / null | 缺失值显示“—”。 |

通用表单的覆盖范围是实际复用 `FinanceFormDialog` / `FinanceRowsDialog` 的预算参数、销量/月度支出、预算版本、成本包及节点、报价、活动操作、岗位管理与历史授权等入口。自定义预算填报编辑器、部门归属调岗表单、完整权限策略编辑器、Excel 导入器等尚未全部接入，不能将此增量视为所有表单已统一。
