## 本次修正

- 原九页只有 BOM 读取、缺少完整预算编制/比较、统一复核、通知和权限操作；现在注册十六个页面，具体覆盖见 README。
- 共用同一公开 REST 合同，Host 仅转发明确白名单内的方法与路径，保持原有 GET/POST/PUT/PATCH，不允许任意路径或内部 API。写入仍由服务端验证角色、能力及对象归属。
- 全量数据范围 `fullAccess` 不作为财务写入资格。只有 FINANCE_STAFF/FINANCE_OWNER 呈现财务写入，权限中心管理进一步要求 FINANCE_OWNER。撤销能力后隐藏入口并退出当前页；临时故障保留已确认权限，401/403 清除权限。
- 总览初次即使用主体筛选，选填数据集失败不导致整个总览失效。预算可用金额使用服务端 `availableAmount` / `availableCumulative`，避免再次减去分配或重复扣减 PR 与付款；正式预算缺失明确提示。
- 事实汇总保留金额字符串。未发布付款/计划批次不展示金额；正式/草稿预算、总部/合众、不同币种、OA 实付/已打 PR/预计 PR 均分列，不在客户端混算。
- 预算编制支持业务假设、销量输入、计算、结果/报表/批次差异、滚动草稿。变更需显式确认；导入异常行和批量定稿逐条回执保留。
- BOM 提案与落账分两步；导出创建与结果回写分两步。新表单阻止重复请求，失败保留输入。列表切换查询后忽略旧响应，提供重试。

## 已完成验证

插件构建/语法/单元测试；桌面 headless gate；真实 Chrome 配合受控 API 的十六页回归，覆盖 BOM 权限、分页、明细、部分失败与重试、失败建包后重试、只读角色、预算计算结果、来源范围、通知已读、权限撤销和分析会话下钻。

## 验证边界

生产网址本次打开后进入统一登录页，因此尚未使用真实已登录租户验收生产数据和写入。源码与公开合同对齐、受控浏览器回归不能代替生产租户验收，不能据此声明生产所有功能已验证。

插件保留桌面交互形式。BOM 支持逐行与 JSON 批量导入（最多 200 行），销量支持逐行导入（最多 500 行）；导出是与网页一致的批次创建/文件引用回写，未实现外部系统连接器。CE 参数支持人工/制造费率及与网页相同的扩展 JSON 对象。表格排序仅针对已加载分页，不代表全量后台排序。

发版需要将源码和桌面快照提交集成到发布分支，按桌面 AGENTS 的 tagged main 流程构建安装。本次没有修改生产服务或自动发起打包。
