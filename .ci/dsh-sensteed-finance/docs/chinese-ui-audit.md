# 财务管理插件中文展示审查

审查日期：2026-10-16。范围：16 个主模块、共用表格/证据明细、表单弹窗、接口异常与会话入口。

## 已修复

| 区域 | 原问题 | 调整 |
| --- | --- | --- |
| 下拉选项 | 结转规则出现 `modeFull` 等翻译键 | 与付款类型、排款优先级一样，显示翻译文案，提交值保持原枚举 |
| 预算与资金 | 版本类型、分配来源、计划状态、审批动作直接显示枚举 | 使用统一业务文案，未知状态提供中文提示 |
| 数据中心 | 同步阶段、回退原因和错误摘要包含技术代码 | 阶段、原因和错误均提供中文；区分同步“部分成功”和付款“部分支付” |
| 预警、复核、权限 | 明细字段名、范围类型、布尔值直接显示英文 | 按业务字段递归展示中文，布尔值显示“是/否” |
| 录入通讯录 | 手机、邮箱列出现 `mobile` / `email` | 使用中文表头 |
| 页面文案 | 侧栏英文副标题、`vs`、`TOP5` | 改为中文，副标题接入语言字典 |
| 异常提示 | 网络、超时、权限、金额校验直接显示英文错误 | 提供中文处理建议，保留业务校验中的金额限制及原有中文说明 |

中文显示只解释已知业务字段：用户填写的名称、备注、单据编号、配置标识和来源内容保持原值。OA、DSS、BOM、PR 等业务系统名称或常用缩写保留。未知证据字段显示“其他字段”，悬停仍可追溯原字段名。

## 验证

- 插件构建、语法与全部 88 项自动检查通过，新增 6 项中文展示回归检查。
- 检查所有页面直接使用的翻译键均有中文文案，覆盖中英文选项展示及原始提交枚举不变。
- 使用独立浏览器和模拟数据走查 16 个模块，覆盖付款/收入/预算录入、失败重试、年度切换、回填、编制、来源记录、通知、权限撤销、成本 BOM 和移动端。
- 针对非空同步记录、权限范围和超时错误验证实际页面，确认未显示对应内部代码。

浏览器验证未写入真实财务数据；未对生产环境做逐笔数据审查。本次更新插件源码与桌面构建快照，已安装客户端需使用包含本次变更的新构建。
