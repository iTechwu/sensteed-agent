## 本轮逐项对照

| 页面 / 操作 | 原有差异或缺陷 | 本轮结果 |
| --- | --- | --- |
| 完整权限配置：选择对象 | 插件编辑对象受限，切换对象会直接清空；成员资格存在宽松默认值 | 两端均支持成员与岗位角色，切换类型 / 角色经未保存确认；明确放弃后加载新对象并重置干净基线。成员按网页权威规则筛选：有用户 ID、已启用、非 LOCAL_MIRROR；部门仅追加当前可用成员。 |
| 完整权限配置：选择功能 | 网页是分组复选框，插件是扁平多选；缺少一致搜索、部分选中和模板体验 | 插件按网页功能分组提供复选、部分选中、功能名称 / 权限码搜索和角色默认功能模板；保留高风险提示。搜索后批选仅影响当前结果，其他选择保留。保存继续要求确认完整替换。 |
| 完整权限配置：数据范围 | 插件只编辑类型对应的主体或部门，保存会丢失其他已存在条件；年度、范围错误难定位 | 两端始终提供主体、部门和年度输入，切换类型不清除已有条件，提交保留同一范围内所有已填写条件。主体 / 部门目录失效、范围缺失、非整数年度、起止倒置等逐字段提示；空端年度不设限。移除网页没有契约依据的 2000—2100 年限制。 |
| 完整权限配置：提交核对 | 网页与插件缺少一致的对象及范围摘要，部分无效输入只能看到汇总错误 | 两端显示人数 / 角色、仅保留功能数、每条范围及主体 / 部门 / 年度。空功能明确表示收回全部功能且不保留范围。提交标记所有错误并聚焦首错；对象、功能或范围变化后，原完整替换确认失效。原因统一去除首尾空白后 1 至 500 字。 |
| 目录与请求反馈 | 旧选择可能在目录变化后提交；刷新失败可能被误报为写入失败 | 目录尚未就绪时阻止提交并可刷新；刷新后的过期选择成为字段错误。保存期间禁用编辑、关闭和重复请求，业务失败保留原文与选择并展示原因。网页写入成功后若列表刷新失败，提示「已保存，列表刷新失败」，避免重复写入。 |
| 恢复继承 / 默认模板 | 网页依赖静默禁用，缺少字段定位、取消和未保存保护 | 原因改为多行，空白 / 超长就地校验并聚焦；取消、关闭、Escape 经未保存确认。同步锁阻止重绘前重复请求和关闭，失败保留原因并展示业务错误。插件沿用已有通用表单保护。 |
| 窄屏和短窗口 | 网页表单整体裁剪可能使长表单尾部难以操作 | 网页对话框允许纵向滚动；两端在窄屏可到达原因、摘要、确认与提交区。继续使用各端组件系统，业务步骤与提交语义保持一致。 |
