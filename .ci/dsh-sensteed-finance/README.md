# Sensteed 财务管理

Sensteed Agent 侧边栏「财务管理」按网页端相同任务组织：总览、我的工作、预算管理、资金管理、经营分析、数据与异常、财务处理、身份与权限、更多工具。待填报任务、部门填报、我的记录和填报活动拥有独立入口；财务代录不混入填报和人员管理。窄窗口使用分组页面选择器。

## 登录与数据连接

财务看板通过 `https://ds.hozonauto.com/api/finance` 的公开 REST 合约读取和写入数据。页面请求只携带当前飞书 SSO Bearer 会话，Datasource 服务端负责租户、角色和操作者校验；插件不再直连任何 MCP 端点。

使用桌面端飞书登录即可。宿主内存保存短期 SSO access token，财务界面每次请求读取当前会话；服务端验证 token 并固定租户和操作者。不再要求用户配置 `DATASOURCE_INTERNAL_API_SECRET`、租户或操作者环境变量。token 不进入渲染进程、状态 API、构建产物或日志。

Datasource 公共服务必须支持 SSO Bearer 鉴权。未登录/过期时显示飞书登录提示；没有财务角色时保留服务端拒绝信息。`DATASOURCE_API_BASE_URL` 仅接受同一公开 Datasource origin 的 `/api` 地址，非法或私有地址会回退到默认地址。

成本 BOM 读取 `https://ds.hozonauto.com/api/ce/packages` 的公开 CE 契约，复用同一飞书会话。入口单独查询 `/finance/permissions/me` 的生效权限（含角色基线与显式授权），不将财务工作区访问权等同于成本工程权限；权限暂不可用时保留已确认的入口，明确撤销后隐藏入口并退出 BOM 页面。CE 服务端继续核验能力、租户及成本包归属。桌面工作台同时支持建包、导入、估算、反算、变更提案与落账、报价、参数、评审和导出回写；写入须服务端认可的财务角色。

## 交互覆盖

| 模块 | 交互 |
| --- | --- |
| 总览/经营 | 年度、主体筛选；预算/PR/付款指标、趋势；下钻到预算子视图与月份 |
| 预算 | 汇总矩阵、月度、明细、PR 台账、差异、调整审批、分配记录、版本与结转规则、保存视图；列表支持字段显隐与表头排序 |
| 资金 | 汇总、排款（现汇/承兑合计校验）、实际回填、收入计划逐笔到账、计划明细逐笔付款登记与冲销、计划准确率（封存快照、上传核对快照、规则签认、复算归因）；付款计划筛选含费用类别与关键词 |
| 预警 | 严重度/状态筛选、分页、详情与来源下钻、规则确认、触发引擎 |
| 数据中心 | 数据质量、导入批次、数据源与运行记录 |
| 我的工作 / 财务处理 / 身份与权限 | 待填报任务、部门填报、我的记录、填报活动、财务代录、组织通讯录、部门归属和成员角色分别进入；同一任务仅有一个目的地 |
| 成本 BOM | 按 `cost.engineering.read` 生效权限显示；成本包分页、物料明细、正算/反算、导入、估算、变更、报价、参数、评审、导出回写；年度/主体筛选不适用于成本包 |
| 预算编制 | 参数与月度支出假设、销量输入、计算批次、三张管理报表、批次差异、滚动预测、版本确认/发布/锁定 |
| 预算比较 | 月结快照、跨年版本、版本明细三类比较；试算与正式口径分开 |
| 复核 | 填报、OA 批次、预算调整、付款计划调整四类队列；同任务批量定稿与逐条回执 |
| 来源与事实 | 总部/合众原始来源记录；已发布事实按状态、业务来源和币种分列，未发布不展示金额 |
| 通知与权限 | 分类、未读、标记已读、业务跳转；本人权限、数据范围、财务负责人授权与撤销 |
| 深度分析 | 风险、成本、预算执行、收入、质量、预测、版本和规则分析，投递到当前会话；无会话时创建会话 |

财务界面仅访问同源 `/api/desktop/sensteed/finance`，宿主再调用 Datasource REST API。所有写入由服务端会话绑定操作者和租户，并保留幂等语义；业务错误不会作为成功返回，客户端无法覆盖操作者/租户。

### 预算与收支录入

费用类别与付款类型显示中文业务名称。预算费用科目从 `/finance/cost-items` 启用主数据中搜索选择，按 `costItemId` 提交，不再借用付款历史或创建自由文本科目；目录加载失败、无启用科目时提供提示与重试。

付款与收入按主体、年度、期间与金额、业务明细排列；年度变化清空旧表单内容并保留数据类型。录入年度默认跟随当前工作台。预算行是对已发布主版本的直接录入：提交前检查所选年度的 `isPrimary` 版本，没有主版本时提示先编制并发布预算，不自动创建或发布版本。金额标为“本行预算金额”，可选月份区分月度与年度行。新年度预算编制请使用“预算编制”或填报任务流程。

2027 年预算使用与网页相同的 `/finance/budget-configuration` 年度快照：一级部门 → 二级部门 → 一级费用类别 → 费用科目；三类费用由映射自动带出，上级变化清空下级。配置未导入、请求失败、部门无映射或主版本缺失均禁止保存，不回退自由输入。其他年度的费用科目可由财务负责人在表单中新增并自动选用，新增失败保留输入，新增中不能提交预算。

通知中的新版填报路由及旧 `data-entry?tab=...` 路由保持任务和年度；预算比较按月结、年度、版本分别定位。未知业务路径明确显示不可用，不静默跳到工作台。

直录入口仅对财务角色及 `budget.submission.edit` 能力开放。保存期间锁定表单、防止重复提交；失败保留输入并显示服务端业务原因（例如“年度 2027 暂无已发布预算版本”），成功刷新财务数据。预算保存回执展示年度、记录编号和金额，可直达刚保存的记录或该年度全部明细。实际回填分别支持付款和收入计划，保留零金额的合法输入；一类计划加载失败不影响另一类计划的回填。

### 人员归属与调岗补录

人员、部门使用可搜索选择器，提交真实目录 ID；补录人员目录独立于通讯录列表的关键词和“只看未绑定”筛选。切换人员清空部门及起始日期，提交时锁定表单并阻止重复登记，失败在弹窗内提示且保留输入。

归属记录支持字段显隐与表头排序，默认最新起始日期优先。起止时间按浏览器本地日期和分钟展示，登记以所选日期的本地零点生效，与网页端一致；未结束记录显示“至今”，来源显示“人工补录”或“通讯录同步”。记录读取失败可重试；超过 50 条时提示仅展示已加载记录，排序不代表全量记录排序。小屏登记表单采用纵向布局。

## 构建与验证

```sh
BRAND=sensteed npm run check
npm run check:datasource -- /path/to/datasource.dofe.ai
```

桌面构建会先重新生成本插件浏览器模块并刷新已安装的 file 依赖。桌面仓库的 `tests/browser/finance.browser.mjs` 使用受控数据覆盖十六页、分析指令、下钻和失败重试；覆盖预算计算结果、来源范围、通知写入、失败保留输入、只读角色、权限撤销等回归；真实财务写入仍应使用测试租户验收。

最新产品统一检查见 [2026-10-16 产品体验审查](docs/product-unification-20261016.md)；历史功能覆盖见 [功能对齐审查](docs/finance-parity.md)。

预算填报与审核：插件与网页 `/filing/budget` 使用同一逐条预算契约，支持本人草稿、两级审核、部门提交与财务确认，以及下一轮复制。审核动作以服务端返回的权限和版本为准。发布前执行 `npm run check:datasource`，检查网页入口、回填文案和权威预算行校验是否一致。详见 [产品统一核查](docs/product-unification-20261016.md)。
